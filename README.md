# 🔐 Creer des login
Un script Bash simple pour creer des comptes utilisateurs avec mot de passe temporaire

## 🚀 Executer le script 


Ce script récupere les identifiants depuis un fichier (un identifiant = une ligne), creer les comptes avec leur répertoire et leur associe un mot de passe de 12 caractère 

```bash
sudo bash create_user.sh
```

### Exemple de sortie 

```text
aZ7@kL2!mP9x
```
